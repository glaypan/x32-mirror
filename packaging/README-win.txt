# x32-mirror 免安装版（Windows 10/11 64 位）

解压到任意目录，双击 **x32-mirror.exe** 即可使用——不需要安装 Python，
也不需要联网下载依赖。

## 第一次使用

1. 双击 `x32-mirror.exe` 打开工作台。
2. 在「01 调音台」卡里填两台调音台的 IP（端口默认 10023，WING 为 2223），
   或点左侧「连接」页填写后保存。型号保持 `auto` 即可自动识别。
3. 选同步模式（单控台 / 双控台全镜像 / 双控台显示独立），点「启动镜像」。
   启动会先做一次安全检测（预检 → 对齐 → 读回核对），完成后提示
   「可以操作调音台」。
4. 手机上访问 `http://<本机IP>:8080` 可打开精简版控制页
   （需在命令行运行 `x32-mirror.exe web --autostart`）。

## 没有调音台也想看界面

双击 **演示模式.bat**：会启动两台模拟调音台并打开界面，推子每 2 秒自动变化，
可以完整体验模式切换、安全检测、暂停同步等全部功能。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `x32-mirror.exe` | 主程序（双击打开桌面界面） |
| `config.json` | 配置文件：调音台 IP、同步模式、热备、云备份等 |
| `config-demo.json` | 演示模式使用的配置 |
| `snapshots/` | 快照存放目录（首次拍快照时自动创建） |
| `oplog.sqlite` | 操作日志（首次运行后自动创建，用于断线补发） |
| `演示模式.bat` | 无硬件体验入口 |

## 网络与地址

- 调音台用 DHCP 或静态 IP 都可以，程序只认你在界面里填的地址；
  若调音台的 IP 会变，建议在路由器上做 DHCP 保留，或给调音台设静态 IP。
- 双机热备需要在两台电脑上分别配置 `config.json` 的 `ha` 节：
  `node_id` 两台不能相同，`peer_host` 填**对方电脑的 IP**（建议固定 IP）。
- 首次启动若弹出 Windows 防火墙提示，请勾选「专用网络」并允许，
  否则手机页面与热备心跳会被拦截。

## 命令行（可选）

打开命令提示符，进入本目录：

```
x32-mirror.exe --version
x32-mirror.exe run --config config.json
x32-mirror.exe web --autostart --http-port 8080
x32-mirror.exe snapshot
x32-mirror.exe --demo
```

## 常见问题

- **Windows 提示"已保护你的电脑"**：程序未做代码签名，点「更多信息 → 仍要运行」。
- **界面打不开**：确认 10199 端口未被占用；也可用
  `x32-mirror.exe gui --browser` 在浏览器里打开。
- **杀毒软件误报**：PyInstaller 打包的程序偶发误报，添加信任即可。
